# SathyaShala

AI-powered attendance and monitoring system for training centres.

## Project Structure
- `frontend/`: React + Vite web dashboard application
- `backend/`: Express.js & MongoDB API server

## Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB instance

### Backend Setup
1. Navigate to the backend folder:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Copy environment configuration:
   ```bash
   cp .env.example .env
   ```
4. Start the backend server:
   ```bash
   npm run dev
   ```

### Frontend Setup
1. Navigate to the frontend folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the frontend development server:
   ```bash
   npm run dev
   ```
